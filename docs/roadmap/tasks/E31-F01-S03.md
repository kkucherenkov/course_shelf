## Goal

A bookmark created offline carries a local id the server has never seen, so after the outbox drains the same bookmark can appear twice until the lesson is refetched.

## Acceptance

- A local→server id map in the Drift schema, written when the outbox entry settles
- The duplicate no longer appears without a refetch
- The Known-limits row is removed from `docs/user-guide.md`
