The card asks for a SQLite-default `docker-compose.yml` plus a Postgres
alternative. There is no SQLite path to default to: Prisma targets Postgres
only, and the sole SQLite in the repository is `drift` inside `apps/mobile`,
which has nothing to do with compose.

Compose itself is done and then some — `docker/compose.yml` (dev),
`compose.override.yml`, `compose.ci.yml`, `compose.prod.yml` and
`compose.release.yml`, all on postgres 18.1, with volumes documented in
`docker/README.md`.

Cancelled rather than reworded: "add a SQLite default" is a database decision,
not a compose chore, and it is not one this project wants.
