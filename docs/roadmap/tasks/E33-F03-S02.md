## Goal

Show what happens after "Transcribe". Today the button starts a course-wide run
and the page then says nothing at all.

## Acceptance

- Progress for a running course transcription on the course page: lessons done
  of total, and the current state
- Terminal states land — finished, failed, cancelled — without a reload
- Cancel is reachable from the same place, through the existing
  `cancelTranscription` route
- Nothing is shown when no run is in flight

`cancelTranscription` all exist
