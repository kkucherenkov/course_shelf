## Goal

One pure function that maps a lesson to the path of its generated transcript, and one guard that keeps that path inside the derived root.

## Acceptance

- `derivedTranscriptPath({ derivedRoot, libraryId, videoPath, language })` mirrors the library-relative path under `<derivedRoot>/<libraryId>/`
- Traversal in `videoPath`, an absolute `videoPath`, or a crafted `language` all raise `DerivedPathEscapedError`
- The guard is a **second, separate** implementation from `lesson-file-locator.ts` — a resolver that accepts either root is one that can be talked into the wrong one
- `transcription.errors.ts` carries the bounded context's domain errors
