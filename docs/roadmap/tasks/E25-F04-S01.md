Finish the writable-artifact fix instead of half-applying it. The scanner writes `*.thumb.jpg` next to the video, which fails on every production install because `COURSES_PATH` is read-only.

## Acceptance

- A failed thumbnail write records a `ScanError` and the scan continues
- A scan that no longer finds a lesson deletes its `Transcript` rows and unlinks the generated file best-effort
