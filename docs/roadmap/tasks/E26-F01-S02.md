## Goal

Lift the cues the browser has already parsed off the `<video>` into a reactive array, so the tab can stay presentational and testable without a real media element.

## Acceptance

- `useTranscriptCues({ videoRef, position, preferredLanguage })` → `{ cues, activeIndex, hasTranscript }`
- Picks the track matching the UI locale, falling back to the first
- A `disabled` track is promoted to `hidden` so the browser parses it; a `showing` track is left alone
- Re-reads on the `<track>` element's `load` event, and tolerates `cues === null`
- `activeIndex` is `-1` when no cue covers the playhead
