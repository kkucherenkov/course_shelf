## Goal

Courses that shipped with subtitles should be searchable too. The transcription run already fills cues for what it generates; this covers everything discovered on disk.

## Acceptance

- The scan parses each `.srt`/`.vtt` sidecar into `Transcript(origin: sidecar)` + `TranscriptCue` rows
- Re-parsed only when the sidecar's `(mtime, size)` changed — a repeat scan over an unchanged library reads no subtitle files
- `group.subtitles` in the scan walk carries `mtime` and `size`, which it currently drops
- A malformed sidecar costs its own transcript, recorded as a `ScanError`, never the scan
