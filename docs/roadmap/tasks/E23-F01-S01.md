## Notes

- Completed: 2026-08-29 (cancelled)
- Result: cancelled — superseded by the two-image + nginx-proxy topology already shipped

The card asks for **one** image that runs the API and also serves the built web
SPA. The repository went the other way and shipped it: `apps/backend/Dockerfile`
and `apps/web/Dockerfile` are two independent multi-stage images, published
separately by `.github/workflows/release.yml` as
`ghcr.io/kkucherenkov/courseshelf-{backend,web}`, and `docker/nginx/` folds them
onto one origin at :8080 so the browser sees same-origin requests.

That is strictly more capable than the carded single image — the SPA scales and
redeploys without restarting the API, and the proxy is where CSP and CORP
already live. Collapsing them back into one image now would be a regression, so
the card is cancelled rather than left open as permanent debt.

The acceptance criteria it carried are met elsewhere: both images are
multi-stage and healthchecks are wired in `docker/compose.prod.yml`.
