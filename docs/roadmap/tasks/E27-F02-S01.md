## Goal

Answer “where was this said, and what minute?” from the existing search endpoint.

## Acceptance

- `GET /api/v1/search` returns a third array `transcripts[]` — additive, no client breaks
- `SearchTranscriptHitDto`: `lessonId`, `lessonTitle`, `courseId`, `courseTitle`, `sectionTitle`, `language`, `startMs`, `text`
- `SearchPort.findTranscriptHits(q, limit, libraryIds)` alongside the existing two
- **Access control:** the same `libraryIds` filter as course and lesson hits; an empty array returns `[]` without touching the database

## Spec diff

openapi.yaml — `transcripts[]` on `SearchResultDto` + `SearchTranscriptHitDto`

## Tests

Adapter spec: `libraryIds: []` short-circuits; a grant on library A never returns a cue from library B. Handler spec for ranking and the limit.
