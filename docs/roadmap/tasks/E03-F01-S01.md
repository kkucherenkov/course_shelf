**Deviation — no token copy** (recorded 2026-08-29; the acceptance line and the
first sub-step claimed it for four months). There is no
`packages/design-tokens/tokens.json`. `src/load.ts:32` reads
`docs/design/shared/tokens.json` from the repo root, so the design bundle is the
single source and there is no second copy to drift out of sync with it. Strictly
better than the carded copy step, which is why it stays.

**Deviation — output paths.** The card named three outputs; the build emits
five, and none at the carded paths:

| Target | Path |
| --- | --- |
| web CSS | `apps/web/app/assets/css/tokens.generated.css` |
| ui CSS (Storybook) | `packages/ui/src/tokens.generated.css` |
| web TypeScript | `apps/web/app/design-tokens.generated.ts` |
| ui TypeScript (Storybook) | `packages/ui/src/design-tokens.generated.ts` |
| mobile Dart | `packages/ui_flutter/lib/src/theme/tokens.g.dart` |

`packages/ui` gets its own copies so Storybook renders without depending on the
web app, and the Dart output lives in `packages/ui_flutter` (the design system)
rather than `apps/mobile` (the consumer). Authoritative list:
`packages/design-tokens/src/build.ts`.
