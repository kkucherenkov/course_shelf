## Goal

Somewhere to start, watch and stop a run. A job measured in days must show honest progress rather than a spinner.

## Acceptance

- Idle offers Start with a “re-transcribe everything” checkbox; running offers Cancel
- Counters shown against the total: skipped / transcribed / failed
- Live progress over the Centrifugo channel the scan card already subscribes to
- Error list, one row per `TranscriptionErrorDto`
- All strings via `t()` in `en` **and** `ru`; `pnpm check:i18n` green
- Component takes translated strings as props, matching every other `Admin*` component
