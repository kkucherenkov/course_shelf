## Goal

Give CourseShelf somewhere legal to write what it generates. `COURSES_PATH` is mounted `:ro` in both production composes, so transcripts and thumbnails need a separate writable volume, and whisper.cpp needs to exist inside the backend image.

## Acceptance

- `AppConfig.derivedPath` (env `DERIVED_PATH`, default `/data/derived`)
- `AppConfig.transcription` — `whisperPath`, `modelPath`, `timeoutMs` (default 6h), `threads`, `language`, and `configured` (false until a model path is set)
- `/data/derived` mounted **writable** in `compose.yml`, `compose.prod.yml`, `compose.release.yml`; `COURSES_PATH` stays `:ro`
- The ggml model is a **mounted read-only file**, never baked into the image
- Backend image carries a pinned whisper.cpp binary; `ffmpeg -version` and `whisper-cli --help` both work inside the container
