## Notes

- Completed: 2026-08-29
- Result: (PR pending)

**ADR-0008 was rewritten, not written.** The acceptance line asked for "SQLite
default, Postgres opt-in". No such thing exists: `provider = "postgresql"` with
the `@prisma/adapter-pg` driver adapter, `postgres:18.1-alpine` in all five
compose files, 15 migrations against Postgres, and a schema that already uses
`@db.Decimal(3, 2)`, two `Json` columns and a descending index. The matching
card [E23-F01-S02](./E23-F01-S02.md) was cancelled on the same grounds a day
earlier.

Writing the ADR as carded would have documented a decision the project made and
then reversed, as though it were current. Instead ADR-0008 records the reversal
and says why — including the cost it accepts (a database container is mandatory;
there is no single-binary first run) — so the SQLite plan is not resurrected by
someone reading the roadmap as a to-do list.

**All ten are retroactive** and each says so in a blockquote at the top, pointing
at the card or commit where the decision was actually made. They were written
against the tree, not from memory: every claim that names a file, a line or a
count was checked (68 CQRS handlers split 31/35, 26 Prisma models with no event
store, 76 Flutter goldens, the five generated token outputs, the Range status
codes in `streaming.controller.ts`).

**Deviation — no code-header backlinks.** `docs/adr/README.md` says to link an
ADR from the code it governs (`// See docs/adr/NNNN-….md`). Not done: that is
edits to a dozen source files for a docs card, and it belongs with the next
change to each file rather than in one sweep.

`docs/` is in `.prettierignore`, so these files are not Prettier-formatted and
`pnpm format` leaves them alone by design.
