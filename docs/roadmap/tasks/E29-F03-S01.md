## Notes

- Completed: 2026-09-16 (cancelled)
- Result: cancelled — the design pre-step was answered by dropping the card, not by picking one of its two options

The card's own note gave the reason and the maintainer settled it on 2026-09-16
while scoping E29: on a single-user instance the order of courses is already in
the owner's head, so a path would be a place to record what nobody needs
recorded. Neither option survived that question. A first-class `LearningPath`
buys an ordered list at the cost of a table, an aggregate, wire contracts and a
new Home surface; a saved filter is cheaper but cannot express arbitrary order,
which was the one thing the card actually asked for.

Flashcards (F01) shipped instead and quizzes (F02) are in flight — both answer
"did this lesson land?", which is what E29 exists for. Sequencing courses is a
different question, and one this library has not yet asked.
