## Goal

whisper.cpp consumes 16 kHz mono PCM. The existing `FfmpegAdapter` owns every ffmpeg call, so the new one goes there rather than into the whisper adapter.

## Acceptance

- `FfmpegAdapter.extractAudio({ videoAbsolutePath, outAbsolutePath, timeoutMs })`
- Emits `-vn -ac 1 -ar 16000 -c:a pcm_s16le`
- Its own transcription-sized timeout, not the 30s used for probing
- Failure raises `AudioExtractionFailedError`
