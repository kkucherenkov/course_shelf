## Goal

Make browse usable on a library of hundreds: filter by what a course *is*, not
only by where it lives.

## Acceptance

- `listCourses` accepts `tag`, `language`, `level` and `studioId`, each
  combinable with the existing `libraryId`, `status`, `durationBucket` and
  `instructorId`
- The browse page exposes all four, and the URL round-trips them
- Filter options come from what the catalogue actually holds — no hard-coded
  language or level list
- Release year is optional; skip it unless it falls out for free
