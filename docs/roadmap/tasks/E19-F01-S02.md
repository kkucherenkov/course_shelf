**Correction to the acceptance wording.** "player uses local path" is not
achievable: `downloaded_lessons.filePath` is AES-GCM ciphertext, and
`VideoPlayerController.file()` on it plays nothing. The player is handed the
`LoopbackDecryptServer` URL (`http://127.0.0.1:<port>/l/<lessonId>?t=…`)
instead, which streams the decrypted bytes with Range support and never writes
plaintext to disk. `LessonVideoSourceKind.localFile` still marks it as the
offline source, which is what raises the "Watching offline" indicator.

**The integrity check compares plaintext lengths, not file sizes.**
`totalBytes` counts plaintext bytes while the container on disk carries a
24-byte header and a 16-byte tag per 256 KiB block, so a literal
"size match" (`file.length() == totalBytes`) would fail *every* intact
download. The gate is
`EncryptedFileFormat.plaintextLengthFor(file.length()) == totalBytes`.

**Deviation — tests.** The planned `integration_test` toggling connectivity was
not added. Offline playback now runs entirely over loopback, so there is no
network dependency left for such a test to toggle; the branches that matter
(intact file, truncated container, deleted file, `totalBytes` still null) are
covered directly in
`test/features/player/lesson_player_offline_source_test.dart`, plus a
concurrency regression test on `LoopbackDecryptServer.start()`. Tracked as a
follow-up rather than dropped.

**Follow-up closed — 2026-08-31 (#275, #280).** The deviation above is settled.
`apps/mobile/integration_test/offline_playback_test.dart` now covers the two
things the host-VM suite structurally cannot reach: a `.csdl` container sealed
by `ChunkedGcmWriter` under a real Android Keystore key, served over the
loopback decrypt URL and **decoded by the real `video_player`/ExoPlayer**; and
the file being removed underneath a URL the player is already holding, which
must answer 404 rather than leaving a spinner. It runs on an Android emulator
in the new `flutter-integration` CI job (`.github/workflows/ci.yml`) — before
that job there was no emulator anywhere, host or CI, which is why
`integration_test/` had never executed at all.
