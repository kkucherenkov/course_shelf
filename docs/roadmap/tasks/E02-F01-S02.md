**Deviation — one file, not a `components/` tree** (recorded 2026-08-29; the
acceptance lines and sub-steps named files that never existed). `packages/specs`
holds a single `openapi/openapi.yaml`. There is no `components/responses/`,
no `components/security/`, no `paths/` — errors are `$ref`-ed inline as
`#/components/schemas/Problem` (defined at `openapi.yaml:7399`) and the schemes
are `bearerAuth` / `cookieAuth` under `securitySchemes` (`openapi.yaml:4936`).

There is also **no global `security:` block**; auth is declared per-operation,
which is what lets the public routes stay public without an explicit
`security: []` override on each. The intent of the card — one reusable error
shape, one bearer scheme, everything under `/api/v1`, `/api/v1/auth/*` outside
the spec body — holds; only the file layout differs.
