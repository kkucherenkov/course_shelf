## Goal

A generated transcript should reach the player through the route that already serves subtitles, with no new endpoint.

## Acceptance

- `locateSubtitle` falls back to a generated `Transcript` when no sidecar matches the language, resolving against the derived root behind its own traversal guard
- A sidecar still wins when both exist
- `LessonDto.subtitles[]` unions sidecars and generated tracks, flagging the latter `generated: true`
- The existing `.srt → WebVTT` conversion is reused unchanged
