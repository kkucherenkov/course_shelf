## Goal

Give the tag model a reader. It has had writers since the catalogue was built
and has never reached a screen.

## Acceptance

- Tag chips on the course card and the course page, from the `tags` field
  `CourseDto` already carries
- A chip is clickable and lands on browse filtered by that tag
- Read-only: no tag editor, no per-user tagging, `set-course-tags` stays an
  internal command
- A course with no tags renders no empty chip row

## Spec diff
