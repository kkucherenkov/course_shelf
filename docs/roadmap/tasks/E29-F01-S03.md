## Notes

Grade buttons collapse the API's 0..5 scale to four: Again→0, Hard→3,
Good→4, Easy→5 — grades 0-2 are all "a lapse" with an identical scheduling
effect per the API's own doc, so nothing is lost. `sourceCueId` is omitted
on transcript-line cards: the web transcript panel reads cues from the
browser's own parsed `TextTrack`, which carries no server-side cue id.
